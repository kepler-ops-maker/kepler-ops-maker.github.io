Proof Random

Public randomness with a trail to check. Proof Random relays the drand quicknet beacon and derives reproducible, nonce-bound integers from it — served free, or metered per-call over x402 on Base Sepolia.

● Free relay — no billing ● x402 testnet — Base Sepolia drand quicknet BLS-pinned verification

Live demo

Draw a number from the latest public beacon. Your browser fetches the beacon straight from drand and runs the relay's exact derivation locally: SHA-256(chainHash:round:randomness:nonce:counter), first 4 bytes big-endian, rejection-sampled into [0, max). Same round + same nonce always gives the same number.

Paying per call with x402

The testnet endpoint speaks x402 v2: the HTTP-native payment protocol. No API keys, no accounts — the payment is the credential.

  1. Call the endpoint. A valid request without payment returns 402 with a base64 PAYMENT-REQUIRED header. Freshness and BLS verification run before the challenge, so a 402 means the beacon itself checked out.
  2. Read the terms. Decoded, the header asks for an exact payment of 1000 base units (0.001) of USDC (0x036CbD53842c5426634e7929541eC2318f3dCF7e) on eip155:84532 (Base Sepolia), to the service wallet, valid for 300 seconds.
  3. Sign and retry. An x402 client signs the authorization and retries with the payment payload; the service settles on-chain and returns the verified sample — blsVerified: true, verifiedChainHash pinned to quicknet.
Testnet honesty. This is a Base Sepolia experiment with test USDC. The challenge flow is live; a fully settled paid response has not been tested end-to-end. Past beacons are public and predictable — never use this for wagers.

Verify it yourself

Every draw cites its source: the drand quicknet chain 52db9ba7…c84e971. Pull the same round from api.drand.sh, recompute the digest and the derivation, and confirm the value — the demo above does exactly this in your browser. For production decisions, verify the BLS signature with an official drand client; the free relay checks a digest, not the signature.
